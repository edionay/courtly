# Visual reference history

The user approved the complete Aguinha-derived Courtly screen pack, with danger buttons corrected to white backgrounds, red text and red borders. The authoritative local copy is [design-system.md](design-system.md); [DESIGN.md](../DESIGN.md) is its root entry point.

The initial gray/teal, Electric and Sport proposals were rejected. They are not implementation references. The former Mantine proposal is superseded by the existing web Tailwind tooling. Aguinha uses NativeWind/gluestack over Tailwind, but those React Native dependencies and product-specific components are not adopted.

Approved PNGs and editable SVGs are indexed in [mockups/aguinha/REVIEW.md](mockups/aguinha/REVIEW.md). Fonts, sport photos and their credits/licenses are local assets. Implement using [frontend-plan.md](frontend-plan.md), [ui-flows.md](ui-flows.md) and [api-contracts.md](api-contracts.md), without depending on the original Aguinha repositories or previous conversations.
