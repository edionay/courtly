Images were downloaded on November 24, 2026. The screen studies reuse these photographs as illustrative sport imagery. The SVG sources embed the image data so the rendered mockups do not depend on remote image loading.

`sport-neutral.svg` is project-authored neutral court-mark geometry on the DS light blue surface. Use it for an unmapped free-text sport, including seeded Futsal. It is not a photograph or a sport-specific court diagram. Keep the actual sport text visible next to the image.
